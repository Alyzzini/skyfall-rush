# Cosmetics and map browser

## Shop

The catalog contains ten trails and eight auras. Six trails and six auras were added:

- Mint Comet, Rose Quartz, Ocean Twins, Sunset Drift, Aurora Stream and Prism Rush.
- Ember Glow, Void Veil, Mint Halo, Storm Crown, Orbital Rings and Prism Crown.

Trails support secondary colors, an optional middle color, tapered widths, short lifetimes and twin ribbons. Auras use glow outlines, twelve-piece halos, eight-piece crowns or sixteen-piece tilted orbital rings. No particles or physical collision are added. Old IDs and ownership remain valid. The shop filters All / Trails / Auras; buying and equipping remain server validated and use coins.

## Maps

The MAPS toolbar button opens CourseBrowser, a separate client module. Every course has an inexpensive stylized theme preview, access state and saved personal best. Previewing a map does not change the current course. Enter/Replay sends the existing server-validated SelectLevel request; locked maps remain preview only. The panel states that switching maps ends the current run. Timers wait for the new course's blue start gate.

Completed maps are saved independently from ranked first-clear rewards. Both assisted and clean completions count toward the completion indicator. Existing cleared maps and earlier unlocked courses populate completion state during profile migration. This uses the existing profile store, preserving wallets, ownership and unlocks. A previously assisted final-course completion may lack historical completion data until it is completed again, but its unlocked map remains selectable.

No gameplay rules or record version change. Studio sources and the full place were saved and source packaging built; no Play-mode test was started at the user's request.
