# Route revision and screenshot corrections

## Preserved systems

Existing four-world identity, hand-edited trees, enclosed environments, speedrun start gates, records, unlocks, checkpoint system, shop, currency, skip disqualification, responsive HUD and audio remain. The refinement changes selected route geometry rather than rebuilding the entire game.

## Movement and pacing

Normal WalkSpeed changes from 22 to 20 and JumpPower from 54 to 50. StarterPlayer uses the same values and explicitly enables JumpPower. Springs retain a distinct assisted launch, reduced to velocity (0, 84, -30) with a 30-speed boost and a closer landing deck. Conveyors push at 7 studs/second. Narrow balance beams are widened and crumble warnings are longer.

Four focused eight-section courses replace the redundant long tails. Checkpoints follow sections 2, 4 and 6. The route length is 768 studs per course, excluding lateral/vertical detours. The environment remains spacious. Obsolete decoration beyond each new finish is removed so it does not resemble a missing route.

## Specific screenshot repairs

1. **Ascent boulders:** six 7.5-stud spherical platforms, with separated landing areas and slight height changes, replace the oversized overlapping stair slabs.
2. **Rounded turns:** corner transitions follow sampled quadratic curves. Circular joins match the deck width and slope, and the surface is lifted slightly above adjoining hubs to avoid coplanar flicker.
3. **Ember crossing:** one continuous curved bridge with a readable sweeper replaces the confusing forked loop and center rail.
4. **Climbing terraces:** Ember and Solar use a forward-progressing rise and descent. There is no overlapping spiral, central cut-through or unrelated tower.
5. **Course ends:** all eight sections remain in every course. The previous empty-tail views came from obsolete decorative structures left beyond the shortened playable finish; those structures are removed.

Sequential route nodes under each section gate require the intended turns before a ranked section is accepted. This prevents an obvious cut from becoming a valid ranked route, but it is not a claim that every physical shortcut has been discovered. The user's playtesting will guide further geometry adjustments.

## Validation status

The user explicitly requested control of gameplay testing. No further Play-mode testing was run after that instruction. Prior automated attempts were partial, used temporary session-only fixtures and do not certify this geometry, full-course completion, touch controls or performance. The temporary traversal driver is not included in the playable project. Edit-mode geometry review and source packaging are separate from gameplay testing.

Movement and route changes use Rush_v7 records. Existing coins, cosmetics, unlocks, wins and cleared-course ownership remain in the same profile store.
